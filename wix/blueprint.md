# Wix AI site

## Minimal

`wix/minimal` contains code and steps to create a minimal serverless Wix website that shows a chat with AI to user.

[`wix/minimal/README.md`](minimal/README.md) describes the steps to create the site.

## In Jaspr

[`wix/jaspr/README.md`](jaspr/README.md) contains code and steps to create the same site but using [Jaspr](https://jaspr.site).

The Jaspr site is also serverless: model runs in the browser, page is static, no backend, no API keys.
