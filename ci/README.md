# E2e eval kit for A2UI SDKs

## Overview

The kit evaluates how AI creates A2UI applications based on:
1. High-level specifications of application, without any tech details about A2UI
2. Information on [GitHub A2UI project](https://github.com/a2ui-project/a2ui)

One experiment:
1. Creates [the application](./blueprints/simple_chat.md) for React, Flutter and Jaspr.
2. Records video for the primary CUJ for each app.
3. Outlines observations and detected issues.

See details in [experiment blueprint](./blueprints/experiment.md).

The experiment is scheduled to run weekly PR with the experiment artifacts.

Example of auto-created PR: https://github.com/polina-c/a2ui-spikes/pull/1
Example of auto-taken video: https://polina-c.github.io/a2ui-spikes-binaries/ci/experiments/2026-09-20-0155/videos/react.webm
