# Simple chat experiment

[a2ui]: https://github.com/a2ui-project/a2ui
[simple_chat]: simple_chat.md

## Goal

This experiment aims to evaluate [a2ui] readiness for implementing applications enhanced with generated UI.

## Steps 

Generate a simple application following the [simple chat blueprint][simple_chat] and evaluate readiness of [a2ui] for implementing this application. Take notes of any issues and improvement suggestions along the way.
